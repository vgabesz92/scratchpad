# Képernyőképek / Screenshots

Ide helyezheted el a projekthez tartozó bemutató képernyőképeket. A fő `README.md` fájl az alábbi fájlnevekre hivatkozik:  
Place your promotional and UI screenshots in this folder. The main `README.md` references the following file names:

- **`main.png`** — A Scratchpad megnyitott állapota a felső panelen, jegyzetekkel és szintaxiskiemeléssel (Fő bemutató kép).
- **`settings.png`** — A Libadwaita beállítóablak.
- **`files.png`** — A mentett fájlok listája / fiókja.

### Tipp képernyőkép készítéséhez GNOME alatt:
- Használd a beépített **`PrtScn`** (Print Screen) billentyűt az interaktív képernyőkép-készítőhöz.
- Mentsd a képeket közvetlenül a `screenshots/` mappába a fenti fájlnevekkel (`main.png`, `settings.png`, `files.png`).
